Step 1: Download all files and ensure that the relative file paths remain unchanged.

Step 2: Open and run app.py.

Step 3: Click the web link displayed in the terminal after running.

Step 4: On the home page, select and click the module you wish to explore or predict.

Step 5: Enter the SMILES formats for the cation and anion, configure the required parameters/conditions, and click the "Predict" button on the page to generate the results.
